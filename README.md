# Baxus Honey Barrel - Wine & Whiskey Market Analyzer

![Baxus Honey Barrel Logo](https://placeholder.com/logo)

## 📝 Overview

Baxus Honey Barrel is a Chrome extension that helps wine and whiskey enthusiasts make informed decisions by scraping product information from various online retailers and instantly comparing prices with listings on the Baxus marketplace.

**[Watch Demo Video](#demo-video)**

## 🌟 Features

- **Real-time Price Comparison**: Automatically matches wines and whiskeys you browse with Baxus marketplace listings
- **Detailed Analysis**: Provides comprehensive information on each product:
  - Current market value
  - Price history trends
  - Investment potential
  - Rarity indicators
  - Similar alternatives
- **Smart Notifications**: Alerts you when you find a bottle priced below market value
- **Watchlist Integration**: Save bottles to your watchlist for price monitoring
- **Export Options**: Download data in CSV format for further analysis
- **Compatible Sites**: Works with major wine/whiskey retailers and auction houses

## 🔧 Installation

### Method 1: Chrome Web Store

1. Visit the [Chrome Web Store](https://chrome.google.com/webstore)
2. Search for "Baxus Honey Barrel"
3. Click "Add to Chrome"
4. Confirm the installation when prompted

### Method 2: Manual Installation

1. Download the latest release from our [GitHub repository](https://github.com/baxus/honey-barrel)
2. Unzip the downloaded file
3. Open Chrome and navigate to `chrome://extensions/`
4. Enable "Developer mode" in the top-right corner
5. Click "Load unpacked" and select the unzipped folder
6. The extension should now appear in your Chrome toolbar

## 🚀 Getting Started

1. **Create a Baxus Account**: Sign up at [baxus.com](https://baxus.com) if you don't already have an account
2. **Link Your Account**: Click the Baxus Honey Barrel icon in your Chrome toolbar and follow the authentication process
3. **Set Your Preferences**: Configure your interests (wine, whiskey, or both) and price thresholds
4. **Start Browsing**: Visit your favorite wine/whiskey retailers and watch the magic happen!

## 💡 How to Use

### Basic Usage

1. Navigate to any supported wine or whiskey retailer website
2. Browse products as you normally would
3. When viewing a product page, the extension will automatically:
   - Display a small notification if the product is found on Baxus
   - Show current price comparisons
   - Provide investment potential rating

### Advanced Features

- **Detailed Analysis**: Click the extension icon while on a product page to see comprehensive market analysis
- **Add to Watchlist**: Use the "Add to Watchlist" button to track price changes over time
- **Export Data**: From the extension dashboard, export your findings to CSV
- **Batch Analysis**: Upload a list of wines/whiskeys for bulk comparison

## ⚙️ Configuration Options

Access the extension settings by right-clicking the icon and selecting "Options" or visiting the Extensions page in Chrome.

| Setting | Description |
|---------|-------------|
| Product Types | Select which products to analyze (Wine, Whiskey, Both) |
| Price Threshold | Set minimum/maximum price points for notifications |
| Notification Style | Choose between pop-up alerts or subtle indicators |
| Data Refresh Rate | Configure how often price data updates |
| Watchlist Alerts | Enable/disable price change notifications |

## 🔒 Privacy

- Baxus Honey Barrel only collects information necessary for price comparison functionality
- We do not track your browsing history outside of supported wine/whiskey retailer websites
- All data is encrypted and stored securely
- You can delete your data at any time through the extension settings

## 🐛 Troubleshooting

**Extension Not Working on a Supported Site?**
- Make sure you've granted all necessary permissions
- Try refreshing the page
- Check if the website structure has changed (report this to us)

**Price Comparisons Seem Inaccurate?**
- Verify that the exact same product (year, size, condition) is being compared
- Our data updates hourly, so there might be slight delays
- Some retailers use different naming conventions, affecting matching accuracy
